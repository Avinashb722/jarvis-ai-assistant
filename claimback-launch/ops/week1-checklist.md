# ClaimBack — Week 1 Execution Checklist

## Day 1–3 · Validate (cost: $0)
- [ ] Pull 10 local HVAC/plumbing shops (Google Maps, 100+ reviews, 5–50 techs)
- [ ] Run `outreach/validation-call-script.md` — log all 10 calls
- [ ] GO/PIVOT/KILL decision per the script's signals

## Day 2–4 · Infrastructure (runs in parallel)
- [ ] Buy 2 send domains (getclaimback.com variants) + 4 Google Workspace inboxes
- [ ] Start Instantly warm-up (14 days — start NOW, it gates week 3)
- [ ] Deploy `site/index.html` (Vercel/Netlify, 10 min) + hook audit CTA to Tally/Typeform
- [ ] HubSpot free: pipeline Lead → Audit Sent → Audit Delivered → Proposal → Won
- [ ] Zapier: Tally submit → HubSpot contact → Slack #leads alert

## Day 3–7 · Pilots
- [ ] Pitch warm/validation-call shops the founding-5 offer (`ops/pilot-offer-and-loa.md`)
- [ ] Sign 3–5 LOAs (lawyer-review the template first — 1hr of counsel, worth it)
- [ ] Collect first invoice exports → run first manual audits
- [ ] File first real claims → log everything in `playbooks/claim-filing-playbook.md`

## Day 5–7 · Pipeline build
- [ ] Apollo list: 300 leads (HVAC/plumbing, 5–100 headcount, Owner/GM/Office Mgr)
- [ ] Load `outreach/cold-email-sequence.md` into Instantly (sequences ready, sending starts when warm-up completes ~day 16)
- [ ] Draft audit-deliverable PDF template from `ops/pilot-offer-and-loa.md` spec

## Legal/compliance (before first paid claim)
- [ ] Lawyer review: LOA + acting-as-agent model per brand T&Cs
- [ ] Form LLC + basic E&O insurance quote
- [ ] NDA template for invoice intake

## Success gates
| Gate | Target | If missed |
|---|---|---|
| Validation calls | ≥4/10 confirm slippage | Re-run plumbing-only angle |
| First audit | ≥$5K found per shop | Check parsing, widen window to 180 days |
| First filings | ≥70% approval | Fix claim package before scaling outreach |
